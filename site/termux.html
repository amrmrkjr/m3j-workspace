opencode
on termux

Run OpenCode natively on Android via Termux. No proot, no chroot, no containers — just a glibc compatibility layer.

how it works

why a compatibility layer?

OpenCode ships as a Linux glibc-linked binary, but Termux uses Android's Bionic libc. These are incompatible — you can't run a glibc binary directly on Termux.

The bootstrap solves this by installing a glibc compatibility layer and creating a launcher that runs OpenCode through glibc's dynamic linker. The launcher unsets conflicting environment variables and hands off execution to ld-linux-aarch64.so.1, which loads the OpenCode binary as a shared library.

execution flow

$ opencode
  │
  ▼
shell wrapper (Bionic binary, native)
  │ unset LD_PRELOAD
  ▼
glibc ld-linux-aarch64.so.1
  │ --library-path glibc/lib
  ▼
OpenCode binary (glibc binary, runs as shared library)
v2 features

all features

The v2 bootstrap adds persistent sessions, safe updates, web access, notifications, and optional Bun support on top of the core compatibility layer.

▣

persistent sessions

opencode-tmux launches in a tmux session with a wakelock — your session survives screen-off. Detach with Ctrl+B D, reattach with tmux attach -t opencode.

↻

safe updates

opencode-termux-update downloads the latest binary while preserving the Termux wrapper. Never run opencode update directly.

◎

web interface

opencode web starts the web UI on http://127.0.0.1:3000. Open in Chrome for a desktop-like experience.

⚙

notifications

Background notifications via termux-notification for session start, updates, and bootstrap completion.

⚡

bun & plugins

Optional --with-bun flag installs bun-termux for plugin management and bunx commands.

⎔

auto-update guard

Config file disables the built-in autoupdater. The wrapper exports DISABLE_AUTOUPDATER=1 to prevent accidental binary replacement.

prerequisites

what you need

Android device (ARM64)
aarch64 required — OpenCode only ships Linux ARM64 binaries. ~1GB free space.
Termux from F-Droid
Must be from F-Droid — the Play Store version is abandoned and incompatible with modern packages.
API key
An Anthropic, OpenAI, or other LLM provider API key for the AI backend.
bootstrap

one command

Open Termux on your Android device and run:

# Clone the repo and run the bootstrap
pkg install git -y
git clone https://github.com/amrmrkjr/opencode-termux
cd opencode-termux
bash projects/termux-opencode/bootstrap.sh

For the full feature set including plugins and Bun support:

bash projects/termux-opencode/bootstrap.sh --with-bun

The bootstrap runs through 12 steps, installing glibc, dependencies, OpenCode, the launcher, and a workspace at ~/opencode/.

commands

daily usage

After bootstrap, these are the commands available on your device:

# Terminal UI (starts OpenCode directly)
cd ~/opencode && opencode

# Web interface (open http://127.0.0.1:3000 in Chrome)
opencode web

# Persistent session (survives screen-off, uses wakelock)
opencode-tmux

# Safe update (downloads latest binary, preserves wrapper)
opencode-termux-update
what gets installed

full breakdown

🔄

glibc layer

glibc-repo + glibc + glibc-runner. Provides ld-linux-aarch64.so.1 and all glibc shared libraries under $PREFIX/glibc/.

▸

opencode binary

Official Linux ARM64 build from GitHub releases. Stored at ~/.local/share/opencode-termux/bin/.

⎔

launcher

A shell wrapper at $PREFIX/bin/opencode that unsets LD_PRELOAD and invokes the glibc loader with the OpenCode binary.

📦

packages

git, ripgrep, python, nodejs-lts, curl, jq, tar — OpenCode's runtime dependencies.

↻

update script

opencode-termux-update in $PREFIX/bin/ — safely downloads the latest binary without breaking the wrapper.

▣

tmux launcher

opencode-tmux — launches OpenCode inside tmux with wakelock and notifications for persistent sessions.

⚙

config & auto-update

~/.local/share/opencode-termux/config.json disables autoupdater. Wrapper exports DISABLE_AUTOUPDATER=1.

⎔

workspace template

A ready-to-use OpenCode project with Termux-optimized configs (compact mode, conservative tokens), curated skills, and Termux-specific AI instructions.

configuration

api key & mobile settings

After bootstrap, set your API key in ~/opencode/.env:

# ~/opencode/.env
ANTHROPIC_API_KEY=sk-ant-...

Or pass it at runtime:

ANTHROPIC_API_KEY=sk-ant-xxx opencode

The workspace opencode.json is pre-configured for mobile:

{
  "terminal": {
    "compact": true,
    "maxTokensPerRequest": 4096,
    "autoApprove": false
  },
  "web": {
    "port": 3000,
    "host": "127.0.0.1"
  }
}

Compact mode, conservative token limits, and web UI binding to localhost for security.

tips

using on mobile

use opencode-tmux for long sessions
opencode-tmux wraps your session in tmux with a wakelock — safe to turn off the screen. Detach with Ctrl+B D, reattach with tmux attach -t opencode.
web mode for Chrome
opencode web starts a local server at http://127.0.0.1:3000. Open in Chrome for a familiar desktop-like interface with your phone's keyboard.
compact mode (default)
The workspace config enables compact mode automatically. Override with opencode --no-compact if you need more detail.
safe update, never opencode update
Always use opencode-termux-update to upgrade. The built-in opencode update downloads an unpatched binary that won't work on Termux.
storage access
Run termux-setup-storage to access shared Android storage at ~/storage/. Bootstrap creates symlinks for ~/Downloads, ~/DCIM, ~/Documents.
plugins need --with-bun
Plugin management and bunx commands require Bun. Re-run bootstrap with --with-bun to install the Termux-compatible bun-termux build.
troubleshooting

common issues

"can not execute: required file not found"
You're trying to run the raw OpenCode binary directly. Use the opencode launcher instead — it routes through the glibc loader.
opencode starts but hangs on network
Missing glibc DNS config. Run: echo 'hosts: files dns' > $PREFIX/glibc/etc/nsswitch.conf
"GLIBC_2.XX not found"
Your glibc version is too old. Run pkg update && pkg install glibc to get the latest.
Install from Play Store doesn't work
Uninstall Play Store Termux and install from F-Droid. The Play Store version is abandoned (stuck on Android 7 API).
Binary download fails
GitHub rate limiting may block downloads. Try again later or download manually and place at ~/.local/share/opencode-termux/bin/opencode.
opencode-tmux fails with "command not found"
Run pkg install tmux termux-api. The bootstrap installs these, but they may need manual setup if skipped.
Web UI not loading in browser
Ensure you're accessing http://127.0.0.1:3000 (not localhost). If using a remote browser, the web server binds to 127.0.0.1 by default for security.
opencode update; won't run after update
You ran opencode update, which replaced the wrapper with a raw binary. Re-run bootstrap: bash bootstrap.sh --skip-deps --skip-workspace
Bun install fails or bunx not found
Bun on Termux needs the bun-termux shim. The bootstrap installs it with --with-bun. If it fails, try manually: curl -fsSL https://raw.githubusercontent.com/Happ1ness-dev/bun-termux/main/helper_scripts/bun-termux-manager | bash -s install
Notification not showing
Ensure termux-api is installed: pkg install termux-api. Notifications require the Termux:API app from F-Droid as well.
background

why this is needed

OpenCode's Linux ARM64 binary has two fundamental incompatibilities with Android/Termux:

glibc vs Bionic libc
OpenCode links against glibc. Android uses Bionic libc. The dynamic linker paths don't exist on Android.
non-PIE executable
OpenCode's binary is not compiled as position-independent (no -fPIE). Android 5.0+ blocks non-PIE executables at the kernel level. Running through glibc's loader avoids this check.

These are not bugs in OpenCode — they're just consequences of shipping a Linux binary for a platform it wasn't built for. The glibc layer bridges the gap cleanly.

For a truly native solution, guysoft/opencode-termux cross-compiles OpenCode (including Bun and WebKit) for Android. It's the most native approach but requires prebuilt binaries from a third party.
