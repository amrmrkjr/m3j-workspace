markdown

basics

headings

Use # to ###### for six levels of headings.

# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6

  - nested item
  - nested item

code

code blocks

Use triple backticks with an optional language identifier for syntax highlighting.

```python
def hello():
    print("hello, world")
```

Or indent with four spaces for an inline code block.

    # this is an indented code block
    echo "hello"
media

links & images

[link text](https://example.com)

![alt text](image.png)

tables

Separate columns with pipes | and headers with dashes -.

| Bob   | Designer |

task lists

Use [ ] and [x] for checkable items.

- [x] completed task
- [ ] pending task
- [ ] another todo

horizontal rules

Three or more dashes, asterisks, or underscores.
