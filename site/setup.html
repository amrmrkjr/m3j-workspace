database

maintenance

The SQLite database grows quickly. Regular vacuuming reduces disk usage and keeps things fast.

# Vacuum the database
sqlite3 ~/.local/share/opencode/opencode.db "VACUUM;"

# Check WAL size
ls -lh ~/.local/share/opencode/opencode.db-wal

# Manual checkpoint
sqlite3 ~/.local/share/opencode/opencode.db "PRAGMA wal_checkpoint(TRUNCATE);"
configuration

opencode.jsonc

Key flags for a lean, fast config. Trim tool output, disable unused features, set a budget model.

{
  "compaction": {
    "enabled": true,
    "max_context_tokens": 8000,
    "strategy": "balanced"
  },
  "tool_output": {
    "max_length": 500,
    "truncation": "head"
  },
  "model": {
    "default": "claude-sonnet-4-20250514",
    "small": "claude-haiku-3-5-20241022"
  },
  "permission": "allow",
  "lsp": false,
  "formatter": false
}
agents & skills

per-project isolation

Keep skills and agents local to each project to reduce context overhead and avoid global pollution.

# Project structure
my-project/
├── .agents/skills/    # project-specific skills
├── .opencode/
│   └── agents/        # project-specific agents
└── opencode.json      # references local paths

# opencode.json
{
  "skills": {
    "paths": [".agents/skills"]
  }
}
