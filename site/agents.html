03

dispatch rules

delegate the primary agent never loads skills or does specialized work — that is coordination's job, tools stay with the fleet
parallel independent tasks dispatch simultaneously — sequential only where sequential is required
verify sub-agents run verification before claiming done; evidence precedes assertion
route unclear scope → m3j-planner first; disagreement → m3j-omniscient; workflow → m3j-workflow skill
models all pinned free-tier — planning on nemotron, review on laguna/longcat, tests on north-mini, execution on deepseek-flash. Don't override.
