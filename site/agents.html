dispatch hierarchy

A commander agent delegates specialized work to sub-agents. Each sub-agent has a distinct model, role, and dispatch trigger. This page catalogs every agent in the fleet.

workflow

how dispatching works

The primary agent (you are talking to it) inspects every request and routes it to the best specialist. Independent tasks go in parallel. Complex jobs go to m3j-planner first for scoping, then to m3j-executor for execution. When in doubt, m3j-omniscient decides.
